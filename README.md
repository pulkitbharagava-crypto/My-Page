# My-Page

## About the Project
This is my personal portfolio website, developed using HTML.
It presents my educational background, technical experience,
personal introduction, and extracurricular interests.

## Features
- Personal introduction
- Profile photo
- Educational background
- Technical experience
- Extracurricular activities
- Links to LinkedIn, Instagram, and GitHub
- Signup form with input fields and selection options
- Navigation between multiple HTML pages

## Technologies Used
- HTML5

## Project Structure
- home.html — Portfolio navigation page
- home1.html — Personal portfolio and introduction
- education.html — Educational background
- techexperience.html — Technical experience
- cocurricular.html — Extracurricular activities
- signuppage.html — Signup form
